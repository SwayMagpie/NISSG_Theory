# Non-Inferential State Sequence Generation (NISSG)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23619774.svg)](https://doi.org/10.5281/zenodo.23619774)


### A Structural Theory of Computation-Free State Sequence Formation

NISSG is a structural theory showing that state sequences can arise  
without inference or computation, based solely on the ordering formed  
from observational facts (“non-breaking transitions”).

NISSGER is the minimal model that satisfies this abstract structure,  
functioning as an **Ensemble Recorder** that can:

- record states  
- reactivate them  
- chain them  
- compose sequences  

all **without computation**.

## 🧠 Core Idea
The agent does not compute transition validity.  
Each observed state already carries the factual guarantee that  
“a non-breaking transition existed in the physical domain.”

Juxtaposition of these facts forms an ordering.  
Next-state selection arises naturally within this ordering.  
State sequences emerge as chains of reactivation.

This structure yields a decisive advantage:

### **Partial observation → full sequence reactivation**  
Grounding, imitation, association, and compositionality  
arise without inference.
